Privacy Policy

Last updated: May 4, 2026 · YouLikeIt is a personal-use software project.

1. Overview

YouLikeIt ("we", "the Service") is a personal content-creation tool. The Service does not operate any cloud servers and does not collect, store, or transmit creator data to a YouLikeIt-controlled backend. All processing and storage happens on the creator's own machine.

2. Data we access

When the creator authorizes a connected platform, the Service accesses only the data needed for that platform's specific purpose.

2.1 TikTok

2.3 Creator-generated content

Videos, narrations, scripts and metadata produced by the creator are stored locally on the creator's machine. They are never uploaded to a YouLikeIt-controlled backend.

3. How we use the data

We use the data only to:

  • Upload the creator's own video content to authorized accounts as drafts or unlisted videos.
  • Display the creator's own connected-account info in the local review dashboard.
  • Surface the creator's own performance metrics from each platform's analytics.

4. Storage & security

All data is stored locally on the creator's device. There is no shared multi-tenant database. OAuth tokens are persisted in gitignored JSON files within the project directory. We recommend:

  • Never commit the tokens/ directory to source control.
  • Use disk encryption (FileVault / BitLocker / LUKS) on the creator's machine.
  • Revoke access from the platform's settings if the device is lost.

4.1 Website analytics

This public website (youlikeit.vara-alta.lat) uses Plausible Analytics, self-hosted by us at analytics.vara-alta.lat. Plausible is a privacy-first, open-source analytics tool that:

  • Uses no cookies and does not require a consent banner.
  • Does not collect or store personal data, IP addresses, or user agents persistently.
  • Does not track you across sites or build advertising profiles.
  • Counts only aggregate page views and anonymous goal events (e.g. which call-to-action was clicked) so we can see whether the site is useful.

Because it is self-hosted, this data never leaves infrastructure we control and is never sold or shared. Legal pages (terms.html, this page) are not instrumented.

5. Sharing

We do not share, sell, or transfer the creator's data to any third party. The only data transmission occurs directly between the creator's device and the platforms they have authorized (TikTok, YouTube).

6. Retention

Local data persists until the creator deletes it. Removal options:

  • Delete the tokens/ directory (revokes local OAuth tokens).
  • Delete the data/ directory (clears local databases).
  • Revoke from TikTok Settings → Security → Manage app permissions.
  • Revoke from Google Account → Security → Third-party apps.

7. Your rights

  • Access — All data is in plain JSON / SQLite files on the creator's device.
  • Delete — Remove any or all data at any time.
  • Revoke — Disconnect platform accounts at any time.
  • Portability — Standard formats, fully portable.

8. Children's privacy

The Service is not intended for use by anyone under 13 years of age and we do not knowingly collect data from children.

9. Changes to this Policy

We may occasionally update this Privacy Policy. The "Last updated" date above will reflect any change.
